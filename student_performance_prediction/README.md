# Student Performance Prediction System

## Project Overview

This beginner-friendly machine learning project predicts a student's final academic performance as:

- Good
- Average
- Poor

The prediction is based on attendance, assignment score, mid-term marks, previous semester grade, study hours per day, and participation in activities.

The project uses a synthetic dataset with realistic distributions and demonstrates the full ML workflow:

1. Generate and load data
2. Handle missing values
3. Encode categorical columns
4. Split data into train and test sets
5. Scale features
6. Train multiple models
7. Compare accuracy
8. Save the best model
9. Evaluate the model
10. Predict performance from user input

## Installation Steps

Open a terminal inside the project folder and run:

```bash
pip install -r requirements.txt
```

## How To Run

### Option 1: Run the menu-driven application

```bash
python main.py
```

Menu options:

```text
1. Train Model
2. Evaluate Model
3. Predict Student Performance
4. Exit
```

### Option 2: Run files separately

Train models and save the best model:

```bash
python src/train_model.py
```

Evaluate the saved model:

```bash
python src/evaluate_model.py
```

Predict a student's performance:

```bash
python src/predict.py
```

### Option 3: Explore the dataset

Open the notebook:

```bash
python -m notebook notebooks/eda.ipynb
```

The notebook creates charts and saves them in the `outputs/` folder.

### Option 4: Open the beginner web page

Open this file in your browser:

```text
web/index.html
```

The web page uses beginner-level HTML, CSS, and JavaScript. It gives a simple browser prediction demo using the same kind of scoring logic as the synthetic dataset. The real machine learning model still runs through the Python files.

## File Explanation

### `src/data_preprocessing.py`

Creates the synthetic dataset and contains all preprocessing functions. It fills missing values, label-encodes text columns, splits the dataset, and scales features.

### `src/train_model.py`

Trains Logistic Regression, Decision Tree, and Random Forest models. It compares their accuracy and saves the best model package as `models/student_model.pkl`.

### `src/evaluate_model.py`

Loads the saved model, prints accuracy, confusion matrix, and classification report, then saves evaluation charts in `outputs/`.

### `src/predict.py`

Accepts user input from the console and predicts whether the student's performance is Good, Average, or Poor.

### `main.py`

Provides a simple menu-driven console application for training, evaluation, and prediction.

### `web/index.html`

Contains the beginner HTML form for entering student details.

### `web/style.css`

Adds simple styling for layout, inputs, buttons, and the prediction result.

### `web/script.js`

Handles form input, calculates a simple performance score, and displays Good, Average, or Poor in the browser.

### `notebooks/eda.ipynb`

Performs exploratory data analysis including overview, null checks, distribution plots, correlation heatmap, pair plot, and class distribution chart.

## Beginner Notes

- The dataset is synthetic, which means it is generated by code for learning purposes.
- Feature scaling helps models treat features fairly even when their ranges are different.
- Label encoding converts text values like `Yes`, `No`, `A`, `B`, and `Good` into numbers that ML models can understand.
- Random Forest can show feature importance, which helps explain which inputs had the strongest effect on prediction.
